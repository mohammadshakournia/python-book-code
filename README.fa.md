## ساختار

هر فصل یک پوشه با نام `CHxx` دارد (مثلاً `CH12` برای فصل ۱۲). کدهای هر فصل با همان ترتیبی که در کتاب آمده‌اند شماره‌گذاری شده‌اند:

```
CH12/
  code01.py            کد اول فصل ۱۲
  code01_output.txt    خروجی‌ای که کتاب برای این کد نشان می‌دهد
  code02.py
  ...
  snippets/            دستورهای غیرپایتونی (مثل pip install) یا نمونه‌های عمداً ناقص
  README.md            فهرست کدهای فصل و بخش مربوط در کتاب
```

خط دستوری که در کتاب بالای هر خروجی دیده می‌شود دقیقاً با همین ساختار یکی است:

```
C:\Users\python-book\ch12> python code01.py
```

## اجرا

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python CH03/code01.py
```

- مثال‌های فصل ۱۸ به `tensorflow` و `torch` نیاز دارند (`requirements-deeplearning.txt`).
- هر فایل در ابتدای خود ۱۰ خط (کامنت نام نویسنده، ایمیل و حقوق به‌علاوه‌ی یک خط خالی) دارد؛ بنابراین شماره‌ی خط در Traceback اجرای واقعی ۱۰ واحد بیشتر از عددی است که کتاب نشان می‌دهد.
- برخی مثال‌ها مانند کتاب به مثال‌های قبلی همان بخش، فایل‌های ورودی یا `input()` وابسته‌اند و مستقل از هم اجرا نمی‌شوند.
- خروجی مثال‌هایی که عدد تصادفی، زمان یا دقت مدل دارند ممکن است با کتاب کمی فرق کند.
